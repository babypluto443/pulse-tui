## 三、逐项说明

### 1. `build.sh` —— 交叉编译（不引 goreleaser）

GOOS/GOARCH 矩阵（linux/darwin × amd64/arm64），`CGO_ENABLED=0 -trimpath -ldflags "-s -w"`，产物进 `dist/` 带 tar.gz。实测四个 tar 包 2.5~2.8MB——单二进制哲学的数字兑现。shell 脚本 30 行干完的事，不值得为它引一个工具链。

### 2. README —— 自解释的三层结构

- **30 秒层**：一句话定位 + 真实 TUI 渲染帧 + 定位对比表（hey/vegeta/k6，复用 SPEC §1 叙事）
- **上手层**：install / flags 表 / 三个典型命令 / 停止语义与指标口径（M3 定义的口径直接外化为文档）
- **信任层**：真实压测数字（pluto_feed）+ 架构图 + 非目标

demo 帧来自 pty 脚本的真实捕获（RPS 100.0、累计 600），不是手编的假图。

### 3. 真实压测 —— pluto_feed（作者自己的服务）

环境：`docker start pluto_feed-mysql`（:3308）+ `go run ./cmd/server`（:8080），数据是真数据（2073 篇帖子）。

```
./pulse-tui -r 100 -d 10s -c 20 "http://localhost:8080/api/v1/feed?limit=20"
```
